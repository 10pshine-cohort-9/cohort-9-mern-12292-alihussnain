# 📝 Notes App — MERN Stack

A full-stack notes application built with the MERN (MongoDB, Express.js, React.js, Node.js) stack. Users can sign up, log in, create, edit, and delete notes with a rich text editor.

---

## 🚀 Live Demo

- **Frontend:** http://localhost:5173
- **Backend API:** http://localhost:5000
- **SonarQube Report:** http://localhost:9000

---

## ✨ Features

- User Authentication (Signup, Login, Logout)
- JWT-based authentication
- Create, Read, Update, Delete notes
- Rich Text Editor (bold, italic, lists, links, images)
- User-specific notes (each user sees only their own notes)
- HTML sanitization for security
- Pino Logger for HTTP request logging
- Global exception handling
- Unit Tests (Backend: Mocha/Chai, Frontend: Vitest)
- SonarQube Code Quality Analysis (Local)

---

## 🛠️ Tech Stack

### Backend
- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- Bcrypt (Password Hashing)
- Pino Logger
- Sanitize-HTML

### Frontend
- React 19
- Vite
- React Router DOM
- Axios
- React Quill (Rich Text Editor)

### Testing & Quality
- Backend: Mocha, Chai, Supertest
- Frontend: Vitest, React Testing Library
- SonarQube (Local Analysis)
